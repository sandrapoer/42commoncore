## Description
Get Next Line is a program that returns a line read from a file descriptor.

External functions used: `malloc`, `free` and `read`.


## Instructions

```bash
make        # builds get_next_line.a
make clean  # removes object files
make fclean # removes object files and get_next_line.a
make re     # rebuilds everything
```
